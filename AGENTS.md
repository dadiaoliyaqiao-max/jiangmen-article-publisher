# Project instructions

For Jiangmen-localized article preparation or publishing, use the project skill at `.agents/skills/publish-jiangmen-articles/` and read its platform playbook before operating any publishing platform.

Keep manuscripts, images, publication trackers, browser exports, credentials, cookies, tokens, and verification data under ignored local-only paths. Never commit them to GitHub.

On a new computer, inspect the current platform management pages before resuming so that an interrupted run does not publish duplicates. Recreate local automations only after confirming the current date, article mapping, and platform status.
